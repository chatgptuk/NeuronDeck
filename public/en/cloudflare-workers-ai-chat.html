Frequently asked questions

Short answers about quota, privacy, and file support.

How does NeuronDeck relate to Cloudflare Workers AI?

NeuronDeck is an open-source web workspace running on Cloudflare Workers. It uses Workers AI for Cloudflare-hosted chat, image, and speech models. Actual availability, price, and quota depend on Cloudflare and your account plan.

Do I need to connect my own Cloudflare account?

No. You can use the site's shared quota when available. Once connected, model requests count toward the Cloudflare account you select. Authorization uses OAuth 2.0 with PKCE; NeuronDeck never reads your Cloudflare password.

Which files can I upload and create?

Compatible models can receive images, TXT, and PDF content. The file tool can create downloadable text, Markdown, CSV, JSON, and PDF results. Exact support still depends on the selected model and request limits.

Are conversations uploaded and stored forever?

Long-term chat history stays in your current browser by default. Content you send is processed by the server and selected model; active stream events are retained temporarily only so a refresh or brief disconnect can resume.
